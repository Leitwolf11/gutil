# Linux x86-64 named pipe creation

Compare GNU Coreutils 9.12 `mkfifo` with two gutil release builds. The
baseline (`32300cc`) creates under the caller umask and adjusts masked
explicit modes afterward. The candidate (`6c1e773`) applies the explicit
mode at creation and corrects inherited ACLs when necessary.

| Item | Environment |
| --- | --- |
| CPU | Intel Core i5-3210M at 2.50 GHz, 2 cores and 4 logical CPUs |
| Affinity | Harness and child processes on logical CPU 3 |
| Memory | 7.61 GiB visible to Linux |
| System | Arch Linux x86-64, kernel 7.3.4-zen2-2-zen |
| Toolchain | rustc 1.100.0 with LLVM 23.1.5, default release profile |
| Storage | Executables on ext4, FIFO operands on tmpfs |

Each invocation creates one or 512 named pipes in a single directory.
Default-mode cases use the inherited `027` umask and expect `0640`. The
explicit cases select `-m 666` and expect `0666`. The benchmark uses
`LC_ALL=C` and `TZ=UTC`, with `POSIXLY_CORRECT` unset. Both gutil builds
receive `--no-config --progress=never --jobs=1`.

Six warmups precede 24 measured rounds in seeded, interleaved order. Timing
includes startup, creation, and process exit. Every invocation must return
success with empty stdout and stderr. The harness checks the type and mode
of every operand and removes the created nodes outside the timed interval.

| Workload | Baseline ms | Candidate ms | GNU ms | Paired reduction vs. baseline, median [IQR] | Paired reduction vs. GNU, median [IQR] |
| --- | ---: | ---: | ---: | ---: | ---: |
| One FIFO, default | 2.84 | 2.67 | 1.19 | -5.0% [-22.4%, 16.2%] | -107.9% [-145.8%, -96.7%] |
| One FIFO, explicit | 2.53 | 2.69 | 1.23 | -1.3% [-4.7%, 5.9%] | -105.1% [-114.8%, -91.1%] |
| 512 FIFOs, default | 4.56 | 4.97 | 3.17 | -3.9% [-18.0%, 5.3%] | -47.1% [-66.3%, -34.0%] |
| 512 FIFOs, explicit | 8.37 | 5.19 | 4.02 | 37.4% [32.5%, 42.7%] | -31.0% [-36.7%, -19.9%] |

The candidate reduces paired median elapsed time by 37.4% against baseline
gutil for the explicit batch. The other gutil comparisons have interquartile
ranges that span zero. GNU has the lowest median in all four cases. The
measurement covers warm input directories on one Linux host.
