# Linux x86-64 terminal detection comparison

Compare gutil `bd7f60974d3e34308bc756a3edc4167d7aca005e` with GNU Coreutils
9.12. Both executables inspect either the same pseudo-terminal slave or
`/dev/null` as standard input. Print mode emits the terminal device path or
`not a tty`. Quiet mode passes `-s` and verifies the exit status with empty
output. The harness also checks stderr and accepts no diagnostics for these
workloads.

| Item | Environment |
| --- | --- |
| CPU | Intel Core i5-3210M at 2.50 GHz, 4 logical CPUs, pinned to CPU 3 |
| RAM | 7.61 GiB visible to Linux |
| OS | Arch Linux x86-64, kernel 7.3.4-zen2-2-zen |
| Compiler | rustc 1.100.0 with LLVM 23.1.5, default release profile |
| Filesystem | Executables on ext4 |
| Reference | GNU Coreutils tty 9.12 |

Each workload uses 100 measurements per executable after 10 warmups, with
seeded interleaving. The measurement includes process startup, execution,
output capture, and exit. The harness verifies the result outside the timed
interval. Both commands run with `LC_ALL=C` and `TZ=UTC`. gutil uses
`--no-config --progress=never`.

| Workload | gutil median (ms) | GNU median (ms) | Paired reduction vs. GNU (median and IQR) |
| --- | ---: | ---: | ---: |
| `redirected-print` | 2.180 | 1.291 | -80.8% [-91.0%, -57.6%] |
| `redirected-quiet` | 2.044 | 1.099 | -82.7% [-93.2%, -68.6%] |
| `pty-print` | 2.176 | 1.253 | -77.9% [-89.3%, -67.8%] |
| `pty-quiet` | 1.961 | 1.043 | -83.8% [-93.6%, -68.1%] |

GNU has the lowest median in all four workloads. These end-to-end measurements
include startup and do not isolate the cost of terminal detection.
