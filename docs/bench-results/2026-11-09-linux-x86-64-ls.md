Measured on November 9, 2026, in Europe/Istanbul. This run compares gutil 0.1.0 at commit `42e4d6009bd01d5709822becd262392c4c5db07c` with GNU coreutils `ls` 9.12.

## Workloads

The benchmark harness created 1,000 regular files named `file-0000` through `file-0999`. Each file contained the seven bytes in `fixture`. Both executables listed the same directory with the C locale and UTC timezone. gutil used its default job limit of four. [Benchmark harness](../../benches/ls.rs)

| Workload | gutil invocation | GNU coreutils invocation |
| --- | --- | --- |
| Name-only listing | `gutil ls -1 .` | `/usr/bin/ls -1 .` |
| Long listing including `.` and `..` | `gutil ls -la .` | `/usr/bin/ls -la .` |

```sh
LC_ALL=C TZ=UTC TMPDIR=/tmp GNU_LS=/usr/bin/ls cargo bench --locked --bench ls -- --save-baseline docs-2026-11-09
```

Each timed iteration includes process startup, listing, formatting, and exit. Standard output goes to the null device. Fixture creation and compilation happen outside the timed iterations. Criterion used a three-second warmup and collected 100 samples per row. The fixture was reused during warmup and measurement. The run used a shared desktop session with no CPU isolation.

## Results

Times are per invocation. Intervals are the 95% confidence intervals reported by Criterion.

| Workload | Implementation | Estimate | 95% interval | Timed iterations |
| --- | --- | ---: | ---: | ---: |
| `-1` | gutil | 2.1814 ms | 2.1505–2.2147 ms | 2,300 |
| `-1` | GNU `ls` | 2.0119 ms | 1.9863–2.0379 ms | 2,500 |
| `-la` | gutil | 4.4625 ms | 4.3656–4.5673 ms | 1,100 |
| `-la` | GNU `ls` | 7.2692 ms | 7.1467–7.4116 ms | 800 |

Compared with GNU `ls` on this fixture, gutil took 8.4% longer for `-1` and 38.6% less time for `-la`. The long listings use different formats. gutil prints numeric owner and group IDs and UTC timestamps. GNU `ls` uses its default owner, group, and timestamp formatting. These measurements apply to this tmpfs fixture and include process startup.
