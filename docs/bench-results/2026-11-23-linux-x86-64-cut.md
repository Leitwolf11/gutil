# Linux x86-64 record selection

Compare release build gutil `b574d62` with GNU Coreutils 9.12 `cut` on
regular files. The workloads cover byte ranges, ASCII fields, UTF-8
character ranges, and a multibyte field separator.

| Item | Environment |
| --- | --- |
| CPU | Intel Core i5-3210M at 2.50 GHz, 2 cores and 4 logical CPUs |
| Affinity | Harness and child processes pinned to logical CPU 3 |
| Memory | 7.61 GiB visible to Linux |
| System | Arch Linux x86-64, kernel 7.3.4-zen2-2-zen |
| Toolchain | rustc 1.100.0 with LLVM 23.1.5, default release profile |
| Storage | Executables on ext4, input and output on tmpfs |

Each workload reads a warm 16,777,208-byte fixture and writes another
regular file. The two ASCII cases use the C locale. The UTF-8 cases use
C.UTF-8. gutil receives `--no-config --progress=never --jobs=1`.

Four warmups precede 12 measured rounds. A seeded shuffle interleaves
GNU, the candidate, and an intermediate gutil build before blockwise
byte selection and the final field scanner. Timing includes process
startup, reads, selection, writes, and exit. The harness verifies exit
status, empty stderr, and the output SHA-256 for every run. Hashing
occurs outside timing.

| Workload | gutil median (ms) | GNU median (ms) | Paired reduction vs. GNU, median [IQR] |
| --- | ---: | ---: | ---: |
| ASCII byte ranges | 16.47 | 23.61 | 29.4% [27.2%, 32.2%] |
| ASCII fields | 32.88 | 45.15 | 26.0% [24.6%, 29.5%] |
| UTF-8 character ranges | 76.68 | 145.80 | 47.7% [45.5%, 48.2%] |
| UTF-8 field separator | 36.76 | 50.16 | 26.4% [20.3%, 32.8%] |

Paired median elapsed times were 26–48% lower than GNU's on this Linux
host. The multibyte-separator case took 6.4% longer than the intermediate
gutil build by paired median. Raw observations include both gutil builds,
all fixture records, and executable hashes.

[Raw observations](2026-11-23-linux-x86-64-cut.json)

```sh
cargo build --locked --release -p gutil --bin gutil
TMPDIR=/dev/shm taskset -c 3 python3 benchmarks/cut_bench.py target/release/gutil \
  --gnu /usr/bin/cut
```
