# Linux x86-64 file search benchmark

Measured on November 17, 2026, in Europe/Istanbul. This run compares
`gutil fd` 0.10.0 at commit `f3ad66f9d93268cb3831c62b9ede1cbaaba0fb13`
with upstream fd 10.5.0.

| Harness | Criterion 0.8.2, optimized Cargo bench profile |

## Workload

Each invocation searches 64 subdirectories with 128 empty text files in
each and applies `--type file --extension txt '^match-'`. An additional
directory under each branch contains one matching name excluded by
`.fdignore`. The harness confirms the same 512 matched paths, comparing
the sorted path sets. gutil sorts its results before writing them.
Processes use the C locale and UTC. gutil disables configuration and
progress output, and upstream fd disables color. Timed iterations include
process startup and discard stdout.

```sh
TMPDIR=/tmp REFERENCE_FD=/usr/bin/fd cargo bench --locked -p gutil --bench fd -- --noplot
```

Criterion uses 10 samples, a 400 ms warmup, and a two-second measurement
target per invocation. The fixture stays resident in tmpfs.

## Results

Point estimates and 95% confidence intervals are in milliseconds.

| Workers | gutil fd | Upstream fd |
| --- | ---: | ---: |
| One | 11.922 [11.519–12.485] | 20.089 [18.239–21.386] |
| Four | 10.069 [10.005–10.147] | 13.317 [13.135–13.469] |

Four workers reduced gutil's point estimate by 15.5% compared with one
worker. Compared with upstream fd, gutil's point estimates were 40.7% lower
with one worker and 24.4% lower with four workers on this fixture.
