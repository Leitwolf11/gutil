# Linux x86-64 line wrapping

Compare GNU Coreutils 9.12 `fold` with two gutil release builds. The baseline
(`8cf610e`) uses the fixed-width path for wrapping without `-s`. The candidate
(`a328d1d`) also searches fixed-width prefixes for horizontal blanks in bulk
and bounds the variable-width blank buffer.

| Item | Environment |
| --- | --- |
| CPU | Intel Core i5-3210M at 2.50 GHz, 2 cores and 4 logical CPUs |
| Affinity | Harness and child processes pinned to logical CPU 3 |
| Memory | 7.61 GiB visible to Linux |
| System | Arch Linux x86-64, kernel 7.3.4-zen2-2-zen |
| Toolchain | rustc 1.100.0 with LLVM 23.1.5, default release profile |
| Storage | Executables on ext4, input and output on tmpfs |

Each workload wraps a warm 16,777,152-byte regular file at 72 display
columns. The ASCII fixture repeats English words in `LC_ALL=C`. The
UTF-8 fixture repeats accented Latin, Japanese, and emoji text in
`LC_ALL=C.UTF-8`. Each fixture is measured with and without `-s`.
Both gutil builds use `--no-config --progress=never --jobs=1`.

The harness runs four warmups and 12 measured rounds in seeded, interleaved
order. Elapsed time includes process startup, reading, wrapping, writing a
regular output file, and process exit. It verifies the full output hash
outside the timed interval and requires empty stderr and successful exit
for every invocation.

| Fixture and flags | Baseline ms | Candidate ms | GNU ms | Paired reduction vs. baseline, median [IQR] | Paired reduction vs. GNU, median [IQR] |
| --- | ---: | ---: | ---: | ---: | ---: |
| ASCII `-w72` | 20.74 | 21.36 | 279.00 | -0.2% [-5.1%, 3.2%] | 92.5% [91.8%, 92.8%] |
| ASCII `-sw72` | 261.01 | 25.37 | 357.95 | 90.2% [90.0%, 90.5%] | 92.9% [92.7%, 93.1%] |
| UTF-8 `-w72` | 143.47 | 149.99 | 233.74 | -4.3% [-6.6%, -1.6%] | 34.9% [31.4%, 39.5%] |
| UTF-8 `-sw72` | 227.78 | 225.74 | 293.72 | 0.5% [-0.8%, 1.7%] | 24.1% [23.1%, 24.9%] |

The candidate lowered paired median time by 24–93% against GNU in these
four workloads. The ASCII blank search improved by 90.2% against baseline
gutil. The candidate also recorded a 4.3% median slowdown against baseline
for the UTF-8 column workload. Timing with other fixtures, width choices,
terminals, or operating systems remains outside this report.
