# Linux x86-64 regular-file paste comparison

Compare gutil commit `154e291e8f0de6b56ef36b2ce37b54461a2ca01c` with GNU
Coreutils 9.12. Each workload reads the same three files with 131,072
96-byte input rows per file, for a total of 36 MiB. The rows are repeated
ASCII characters followed by a newline. Parallel mode uses tabs by default
or cycles through colon and semicolon. Serial mode uses `-s` with tabs.

| Item | Environment |
| --- | --- |
| CPU | Intel Core i5-3210M at 2.50 GHz, 4 logical CPUs, pinned to CPU 3 |
| RAM | 7.61 GiB visible to Linux |
| OS | Arch Linux x86-64, kernel 7.3.4-zen2-2-zen |
| Compiler | rustc 1.100.0 with LLVM 23.1.5, default release profile |
| Filesystems | ext4 executables, tmpfs inputs |
| Reference | GNU Coreutils paste 9.12 |

The harness compares SHA-256 of complete output outside timing. Three warmup
rounds precede 16 measured rounds in seeded interleaved order. Timed
invocations send stdout to the null device and include startup and exit.
The harness verifies successful exit and absent diagnostics. Both executables
use `LC_ALL=C` and `TZ=UTC`. gutil uses
`--no-config --progress=never --jobs=1`.

| Workload | gutil median (ms) | GNU median (ms) | Paired reduction vs. GNU (median and IQR) |
| --- | ---: | ---: | ---: |
| parallel | 34.23 | 121.37 | 72.0% [71.5%, 72.5%] |
| serial | 37.91 | 176.40 | 78.5% [77.4%, 79.2%] |
| cyclic | 34.14 | 121.12 | 71.5% [70.1%, 72.9%] |

On this host, gutil had the lower median in all three workloads. The
measurement covers warm regular files with fixed-size records. It does
not establish throughput for interactive input, very short invocations,
or multiple operating systems.
