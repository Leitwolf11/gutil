# Additional commands

Gutil hosts additional tools in the same executable as its Coreutils commands.

| Command | Capabilities | Reference |
| --- | --- | --- |
| `gutil eza` | Planned directory listings with tree and grid views, file type icons, and Git status. | [eza](https://github.com/eza-community/eza) |
| `gutil duf` | Planned mounted filesystem discovery, capacity and free-space reporting, filters, and JSON output. | [duf](https://github.com/muesli/duf) |
| `gutil fd` | [Recursive file search](cli.md#fd) with smart-case patterns, ignore rules, extension and type filters, and NUL-delimited output. | [fd](https://github.com/sharkdp/fd) |

These three commands are
outside the [GNU Coreutils coverage target](coreutils-coverage.md).
